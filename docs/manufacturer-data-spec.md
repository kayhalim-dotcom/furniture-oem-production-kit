# Production Drawing and OEM Furniture Standards

## 1. Drawing requirements

Every furniture production drawing should include the following information:

- Product name and revision number
- Date and responsible owner
- Internal drawing number
- Unit of measure (mm preferred)
- Front, side, top, and exploded views
- Overall dimensions and component dimensions
- Material specification and thickness
- Tolerance values
- Edge finishing and surface finish
- Hardware callouts and install positions
- Assembly sequence and notes
- QC acceptance criteria
- Packaging reference

## 2. Recommended dimension standards

- Use millimeters as the default unit
- Show all dimensions to 1 decimal place unless a tighter tolerance is required
- Include both nominal and finished dimensions when needed
- Mark primary dimensions with bold and consistent line weights

## 3. Material and manufacturing notes

Recommended production standard notes:

- Core material thickness tolerance: ±0.5 mm
- Laminate thickness tolerance: ±0.2 mm
- Drill position tolerance: ±0.5 mm
- Edge banding coverage: 100% on exposed edges
- Flatness tolerance: ≤ 1 mm per 1000 mm
- Screw pilot hole clearance: based on hardware spec

## 4. Surface finishing standards

- Edge banding: PVC or ABS, matching finish
- Surface finish: laminate, melamine, veneer, or painted surface
- Color and gloss to be recorded on the product spec sheet
- Touch-up and scratch inspection criteria to be included in QC checklist

## 5. Hardware and fasteners

Standardize hardware codes with:

- name
- material
- size
- quantity per unit
- installation position
- torque or fastening requirement

## 6. Quality control checkpoints

At minimum check:

- dimensions match approved drawing
- finish quality and color consistency
- edge banding is complete and clean
- screw placement is accurate
- drawer or door alignment is within tolerance
- packaging protection is adequate

## 7. Packaging and dispatch requirements

- Each component should be labeled with part number and quantity
- Fragile elements should be protected with foam or corrugated inserts
- Final shipping carton should show product code, quantity, weight, and destination
- Include assembly / care instructions inside the packaging when required

## 8. Revision control

Every drawing should have:

- project ID
- revision number
- date
- change summary
- approver name

This is essential for OEM manufacturing where product consistency and traceability matter.
