# QC Checklist

## Pre-Production

- [ ] Material certificates reviewed
- [ ] Panel thickness verified
- [ ] Core material moisture checked if needed
- [ ] Hardware batch confirmed

## In-Process Inspection

- [ ] Panels cut to approved size
- [ ] Edge banding completed and clean
- [ ] Drill positions within tolerance
- [ ] Clean finishing on exposed edges

## Final Inspection

- [ ] Cabinet dimensions match drawing ±1 mm
- [ ] Doors align and open smoothly
- [ ] Hinge installation secure
- [ ] Shelves level and stable
- [ ] Surface finish free from scratches and dents
- [ ] Packaging labels complete
